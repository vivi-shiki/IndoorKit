# IndoorKit — 院内位置情報管理システム

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

ブラウザだけで動く、病院向けの屋内測位（RTLS）・資産管理のデモです。土台には、MapLibre GL JS の上に TypeScript でゼロから作った屋内地図 SDK を使っています。

**オンラインデモ：<https://vivi-shiki.github.io/IndoorKit/?lang=ja>**

人物・機器・建物はすべて架空です。施設は「さくら総合病院」で、5 階建ての 3 棟が各フロアの連絡通路でつながっています。

## デモの内容

### リアルタイム位置監視

院内のスタッフ・患者・医療機器の現在位置を表示します。タグは廊下を歩き、ドアから部屋に出入りし、フロア移動はエレベーターか階段だけで行います。

- タグ数は 500・2,000・5,000 から選べます。位置は毎秒更新され、更新の間も滑らかに動きます。
- タグをクリックすると、直近 10 分の軌跡を再生します。
- パフォーマンスパネルにフレームレート、フレーム間隔、オンラインのタグ数を表示します。

![リアルタイム位置監視](docs/images/tracking.png)

### 医療機器の分布

フロアごとに機器がどこに集まっているかを表示します。3 m 以内の機器は 1 つの点にまとめ、点の数字が台数です。ヘッダーにはそのフロアの集まりの数と機器の台数を表示します。

![医療機器の分布](docs/images/assets.png)

### 立入制限エリア警報

3F の ICU を立入制限エリアに設定しています。タグが出入りすると、警報が一覧に追加され、タグの位置にポップアップが表示されます。

![立入制限エリア警報](docs/images/alerts.png)

### 混雑状況ヒートマップ

直近 1・5・15 分の各フロアの混雑エリアを表示し、人員配置や混雑の把握に使えます。

![混雑状況ヒートマップ](docs/images/occupancy.png)

### 全ページ共通

- フロア切替（1F～5F）。全棟が同時に切り替わります。
- 日本語・英語・中国語に対応し、地図内の部屋名も切り替わります。
- ライト／ダークテーマ。どちらでも文字は WCAG AA のコントラストを満たします。
- 言語とテーマはブラウザに保存され、次回もそのまま表示されます。

## 技術的なポイント

- **プラグイン機構を持つ屋内地図 SDK。** `definePlugin` でプラグインと依存関係を宣言すると、依存順に読み込まれ、プラグイン API には完全な型が付きます（例：`map.plugins.cluster.clusters()`）。
- **設計段階からメモリリークを防止。** プラグインが作ったソース、レイヤー、リスナー、タイマー、Worker はすべて `ResourceTracker` に登録され、`destroy()` で作成と逆順に解放されます。メモリ回帰テストでは全ページを繰り返し切り替え、JS ヒープ、Worker、登録済みリソースを確認します。
- **オープンなデータ形式。** 地図データは IMDF（OGC コミュニティ標準）で、要素間の参照や ID の一意性も含めて zod で検証します。架空の病院はスクリプトで生成するため、データを再現できます。
- **データからスタイルを生成。** 部屋の色と 2.5D の高さは部屋の種類とテーマで決まり、壁と部屋は `fill-extrusion` で立体化するので 3D モデルは不要です。言語とテーマは地図を作り直さずに切り替わります。
- **リアルタイムデータはメインスレッドの外で処理。** シード付きで再現可能な測位シミュレーターを Web Worker で動かし、Comlink でページとやり取りします。
- **空間アルゴリズム。** 軌跡履歴付きの補間移動、KDBush インデックスによる半径クラスタリング、Flatbush インデックスと点の多角形内判定によるジオフェンス、サンプルを「分 × グリッド」で集計してメモリ使用量に上限を設けたヒートマップ。
- **E2E までテスト。** 単体テストは WebGL を使わないメモリ上の偽の地図で SDK を動かします。Playwright はテスト用フックで実際のページを操作し、両テーマのコントラストを確認し、Chrome DevTools Protocol でヒープの増加を計測します。GitHub Actions ですべてのテストを実行し、GitHub Pages にデプロイします。

## 技術スタック

TypeScript（strict）· MapLibre GL JS · IMDF · zod · Web Worker + Comlink · KDBush · Flatbush · Turf · Vite · pnpm workspaces · Vitest · Playwright · Biome · GitHub Actions + GitHub Pages

## ディレクトリ構成

| パス | 内容 |
| --- | --- |
| `packages/core` | 地図の生成、プラグイン機構、リソース管理、イベント、スタイルとテーマの生成 |
| `packages/imdf` | IMDF の読み込み・検証・変換 |
| `packages/plugins` | フロア、リアルタイム位置、クラスタ、ジオフェンス、ヒートマップ、多角形、線、ポップアップ、マーカーの各プラグイン |
| `tools/venue-gen` | 架空の病院の生成スクリプト |
| `tools/rtls-simulator` | タグ移動シミュレーターと Worker 用データプロバイダー |
| `apps/playground` | オンラインデモの 4 ページ |

## ローカルで動かす

Node.js 22 と pnpm が必要です。

```bash
pnpm install
pnpm build
pnpm --filter playground preview
```

<http://localhost:4173/IndoorKit/> を開いてください。
